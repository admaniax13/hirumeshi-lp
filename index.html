Slackの投票には、締切も同票ルールもない。
だから決まらない。ひるメシ投票は、そこを決めました。

HOW IT WORKS

使い方は、3ステップ。

  1. 1

    候補を3件入れる

    幹事がお店の候補を3件まで登録。いつもGoogleマップで探している、あの3件でOK。

  2. 2

    チームが投票

    投票するたびに、その時刻が記録されて全員に表示されます。

    11:41 Cさんが「定食 さくら」に投票
  3. 3

    11:55に自動決定

    締切は自動。同票でも決定ルールで、必ず1店に決まります。

TIE-BREAK RULE

同票なら、
先にその票数に届いた店が勝ち。

11:55の時点で票数が並んだら、その票数に先に到達した候補を採用します。だから、すべての投票に時刻がついています。

例：4人チームの投票ログ

11:32 A → 麺処 たけ たけ 1票
11:38 B → 定食 さくら さくら 1票
11:41 C → 定食 さくら さくら 2票 ★ 先に2票へ到達
11:50 D → 麺処 たけ たけ 2票 2票へ到達（9分おそい）
11:55 締切。2票 対 2票で同票

よくある質問

料金はかかりますか？

すべての機能を無料で使えます。

Slackの投票機能と何がちがいますか？

締切（11:55）と、同票のときの決め方があることです。どんな票の割れ方でも、時間になれば必ず1店に決まります。

同票になったら、どうなりますか？

並んだ票数に「先に到達した」お店を採用します。たとえば2票ずつで並んだら、2票目が早く入った方に決まります。

なぜ投票の時刻が表示されるのですか？

同票のとき、どちらが先に届いたかを全員が確認できるようにするためです。結果の理由が見えるので、もめずに決まります。

何人のチームで使えますか？

2〜5人のチームを想定しています。幹事は持ち回りでも大丈夫です。

締切時刻は変えられますか？

はい、チームごとに変えられます。初期設定は11:55なので、そのままでも使えます。ランチの時間がずれるチームは、幹事が締切時刻を変更してください。
